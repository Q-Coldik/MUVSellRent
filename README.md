# MUVSell Rent — плагин FunPay Cardinal

Перепродажа аренды Steam-аккаунтов с [muvsell.store](https://muvsell.store) на FunPay — без своих аккаунтов.

Покупатель оплачивает ваш лот на FunPay → плагин арендует аккаунт на MUVSell через API (списывает ваш баланс MUVSell по цене сайта) и сразу присылает логин и пароль в чат. Разница цен — ваш заработок, наценку задаёте сами.

Плагин бесплатный, код открыт — это один файл [`MUVSellRent.py`](MUVSellRent.py).

## Что умеет

### Выдача и покупатели

- **Автовыдача** логина и пароля сразу после оплаты — днём и ночью, без вашего участия
- **Коды Steam Guard** по команде `!код` — свою команду можно задать, если на `!код` у вас отвечает другой плагин
- **Продления:** каждая покупка лота выдаёт новый аккаунт, а продлить текущий — командой `!продление 3 часа`: плагин создаёт временный лот на нужный срок, оплата добавляет время к тому же аккаунту
- **Английский:** кто пишет английские команды (`!code`, `!help`…), тому плагин отвечает по-английски — коды, время, продления, предупреждения
- **Шаблоны сообщений** с превью: выдача, предупреждения о конце аренды, ответы на команды
- **Возвраты:** полный возврат на FunPay сразу завершает аренду этого заказа; если выдача не удалась — автовозврат

### Лоты на FunPay

- **Автовыставление** по играм в их разделы FunPay — на все сроки из «Длительностей» по вашим шаблонам текста; можно остановить кнопкой «⏹ Остановить» и продолжить с того же места
- **Steam «Аккаунты с играми» и «Прочие игры»** — по кнопке, для игр без своего раздела на FunPay
- **Новые игры:** о новых играх на MUVSell плагин пишет сам — одно уведомление со списком и кнопкой «🚀 Выставить»
- **Синхронизация цен** с наценкой — общей, по категориям или у каждой привязки
- **Синхронизация наличия:** нет свободных аккаунтов — лот снимается, появились — возвращается; `{stock}` в названии или описании показывает число свободных аккаунтов и обновляется сам
- **Свой ID у каждой привязки** (`rentM-1001`) в описании лота — одинаковые или переименованные лоты не путаются
- **Переустановка без потерь:** «🔎 Найти мои лоты на FunPay» находит лоты плагина и возвращает привязки, «Создать недостающие» не плодит дубли и пересоздаёт лоты, удалённые на сайте FunPay
- **Лимиты FunPay:** на «Много предложений» плагин ждёт и пропускает только переполненный раздел, остальные выставляет дальше
- **Массовые операции:** перезапись текстов у существующих лотов, пересчёт цен, удаление нескольких лотов с подтверждением

### Оффлайн-активации «💿 игра навсегда»

- Кнопка «🤖 Выставить недостающие» выставляет игры оффлайн-каталога MUVSell в их разделы → «Оффлайн активации», «🔁 Автодобавление» — новые игры по мере появления
- После оплаты покупатель получает логин, пароль и инструкцию; код Steam Guard — тем же `!код`, данные ещё раз — `!офлайн`
- Оплата выдач: по цене MUVSell за каждую, **лицензией** на игру (один раз — дальше её выдачи бесплатны) или **подпиской продавца** на весь каталог; режим «только оплаченные» продаёт только игры с лицензией или по подписке
- Лот снимается, когда у игры нет аккаунтов

### Надёжность

- **Защита при сбое:** если MUVSell не отвечает 5 минут, плагин снимает свои лоты и возвращает их, когда связь вернётся; «🙈 Скрыть все лоты» — пауза всех лотов одним нажатием
- **Ни одного потерянного заказа:** заказ, оплаченный, пока Cardinal был выключен или перезапускался, выдаётся при запуске; выдача, оборванная перезапуском, продолжается; повтор запроса не выдаст второй аккаунт и не спишет деньги дважды
- **Снятые лоты остаются снятыми:** если их включило «Восстановление лотов» Cardinal, вы вручную или другой плагин — плагин снимет их снова, чтобы не ловить возвраты
- **Любой хостинг:** если сервер не достаёт до muvsell.store, плагин сам идёт через запасной адрес; свой прокси — по желанию, мёртвый прокси не останавливает заказы
- **Низкий баланс:** баланс MUVSell упал до порога — плагин снимает лоты и пишет об этом, после пополнения возвращает их сам
- **Уведомления о проблемах:** golden_key FunPay больше не действует, закончилось место на диске — плагин пишет в Telegram и объясняет, что делать
- **Автообновление:** новая версия ставится сама, когда 3 минуты нет заказов и команд покупателей (выключается)

### Учёт

- Статистика продаж и прибыли (возвраты не считаются в прибыль)
- Список активных аренд, карантин проблемных лотов, категории уведомлений, диагностика связи

## Установка

1. Нужен FunPay Cardinal (проверено на 0.1.17.15).
2. Скачайте [`MUVSellRent.py`](MUVSellRent.py) и положите в папку `plugins/` Cardinal, перезапустите его.
3. Зарегистрируйтесь на [muvsell.store](https://muvsell.store), пополните баланс и создайте API-ключ: **Профиль → API**.
4. В Telegram-боте вашего Cardinal напишите `MUVSell` (или **Плагины → MUVSell Rent → Настройки**) — вставьте API-ключ, задайте наценку и нажмите «Автовыставление».

Карту разделов FunPay плагин скачивает с сайта сам, обновления плагина тоже приходят с сайта.

## Команды покупателя

| Команда | Что делает |
|---|---|
| `!код` | Код Steam Guard |
| `!данные` | Логин и пароль ещё раз |
| `!время` | Сколько осталось аренды |
| `!продление 3` / `!продление 2д` | Продлить этот аккаунт на 3 часа / 2 дня: плагин создаст временный лот, оплата добавит время |
| `!офлайн` | Данные оффлайн-игры ещё раз |
| `!кик`, `!пароль` | Выкинуть чужие сессии, сменить пароль (если продавец включил) |
| `!помощь` | Список команд |

У каждой команды есть английский вариант (`!code`, `!data`, `!time`, `!extend`, `!offline`, `!kick`, `!password`, `!help`). В сообщении с выдачей есть строка «🇬🇧 English? Type !help». Выключается в **Настройки → ⚙️ Прочее**.
